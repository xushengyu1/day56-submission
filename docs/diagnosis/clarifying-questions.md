## 2026-07-16 PRD 迭代回答

| 原问题 | 用户回答 / 形成的结论 | 是否改变方案 |
|---|---|---|
| 用户和审核角色如何划分 | 业务用户为失主/拾得者；统一管理员是异常审核角色；AI 不是角色；拾得者始终保管实物 | 是，删除实物保管人和失物招领处角色 |
| 图片是否参与匹配 | 拾得者支持上传整体图片供失主浏览，但不使用图像识别、不进入匹配评分 | 是，保留图片上传但拒绝视觉 AI 路线 |
| 是否真实注册登录 | 实现普通用户基础注册登录，管理员账号预置 | 是，替代模拟账号切换方案 |
| 隐藏问题由谁产生 | 拾得者手动设置问题和标准答案；AI 只引导/检查 | 是，替代 AI 自动生成问题方案 |
| 拾得者未填写隐藏信息怎么办 | 至少两组有效隐藏问答才可发布；否则只能保存草稿 | 是，形成发布硬门槛 |
| 可信程度如何使用 | 候选分、隐藏核验分、综合认领可信度分开；高可信满足全部门槛时自动待交接，其余管理员复核 | 是，形成两路状态流转 |
| 谁确认已完成认领 | 实物交接后仅由拾得者标记“已认领” | 是，管理员不确认实物交接 |
| 产品形态 | Web 系统：一个 Web 前端 + 一个服务端 | 是，技术端边界明确 |
