### 宋姿毅个人说明

宋姿毅负责把业务问题转化为可执行的产品、设计和前端方案：从角色职责、状态
边界、候选评分和双类型核验出发，持续维护 PRD、方案比较、详细设计、开发计划
与证据链；完成三类角色的 UI 和 React 页面，并在联调阶段统一地点、类别、字段、
状态、登录和 API 契约。对 AI 建议并非直接接受，而是先后否决或修正 SSR、默认
OpenAI 模型、手工隐藏问题、跨类别匹配和背景信息混入等方案，并通过前端测试、
直接模型调用和文档 Review 区分已验证事实与待验证边界。

### 徐胜宇个人说明

徐胜宇负责将设计落成可运行后端和真实联调闭环：建立 FastAPI、数据库、迁移、

T00～T19 开发证据和最终回归结果为主要依据。
