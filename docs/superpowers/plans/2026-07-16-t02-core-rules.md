# T02 Core Rules Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (recommended) to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement deterministic identity verification, OTHER question validation, candidate scoring, stable Top 5 ranking, and record/claim state machines.

**Architecture:** Four small pure-function modules consume T01 enums and frozen dataclasses. No database or provider calls are allowed; later services depend on these functions instead of duplicating rules.

**Tech Stack:** Python 3.11+, standard library `unicodedata/hashlib/hmac/datetime`, dataclasses, pytest.

## Global Constraints

- Write and observe each failing unit test before its production function.
- Never include full identity numbers or answer text in exception messages.
- Preserve T00/T01 tests and run full backend regression before commit.
- Use exact T01 enum values; do not create duplicate status enums.
