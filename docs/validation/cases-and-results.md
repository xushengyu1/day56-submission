## 3. 模型 spike 最小数据集

至少准备 8 张不含真实个人数据的合成/脱敏图片：

1. 清晰居民身份证样例 2 张；
2. 模糊、反光身份证样例 2 张；
3. 普通物品（雨伞、水杯、耳机）3 张；
4. 不相关或损坏图片 1 张。

每张记录：期望类型、期望名称、期望公开特征、号码期望（仅合成数据）、实际结构化输出、置信度、拾得者需修改字段、耗时和错误。

## 4. 通过门槛

| 能力 | 设计阶段建议门槛 |
|---|---|
| 普通物品提取 | 8 张 spike 中至少 6 张能生成可用名称草稿；所有错误都可人工修改 |
| 证件号码 | 不要求模型零错误；要求拾得者确认后精确比对 100% 按确认值执行 |
| 公开泄露 | 候选 DTO、普通日志和截图中完整号码出现次数必须为 0 |
| 失败降级 | 模型超时/非法结构/脱敏失败均不得导致数据丢失或原图公开 |
| E2E | 身份证件和其他物品各至少 1 条完整主路径通过 |
