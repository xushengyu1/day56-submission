### TC-B01：阈值边界（候选分=80）

**场景**：候选匹配分恰好等于自动通过阈值 80。

**验证要点**：
- [ ] 候选分=80 时仍满足高可信门槛（≥80 含等于）
- [ ] 候选分=79 时不满足高可信门槛

### TC-B02：阈值边界（隐藏核验分=85）

**场景**：隐藏核验分恰好等于自动通过阈值 85。

**验证要点**：
- [ ] 核验分=85 时仍满足门槛
- [ ] 核验分=84 时不满足门槛

### TC-B03：隐藏问答刚好两组

**场景**：拾得者只设置两组隐藏问答，刚好满足发布门槛。

**验证要点**：
- [ ] 两组问答可以发布
- [ ] 一组问答时只能保存草稿

### TC-B04：回答次数限制

**场景**：同一认领申请提交第 2 次回答。

**验证要点**：
- [ ] 第 1 次回答正常提交
- [ ] 第 2 次回答正常提交
- [ ] 第 3 次回答被拒绝

### TC-F01：AI Embedding API 超时

**验证要点**：

- [ ] 用户数据不丢失
- [ ] 错误日志记录

### TC-F02：AI 核验 API 超时

**场景**：OpenAI GPT API 调用超时（>10 秒）。

**验证要点**：
- [ ] 核验分按"无法判断"处理
- [ ] 进入管理员复核
- [ ] 不伪造 AI 结果
- [ ] 错误日志记录

### TC-F03：AI 输出格式异常

**场景**：LLM 返回的 JSON 不符合预期结构。

**验证要点**：
- [ ] 重试 1 次
- [ ] 仍失败则按"AI 异常"转管理员
- [ ] 保存原始异常输出到日志
