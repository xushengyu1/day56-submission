# 风险与边界场景

**更新日期：** 2026-07-17

| 风险 / 边界 | 当前处理与证据 | 残留风险 |
|---|---|---|
| 完整身份证号泄露 | 只允许出现在 identity-confirmation 请求体；E2E 扫描 URL、storage、普通 payload 和页面均未命中 | 服务端内存和基础设施日志仍需按生产环境配置审计 |
| token 泄露 | 浏览器仅内存保存；E2E 证明 URL/localStorage/sessionStorage 无 token | 整页刷新会按设计退出登录，需要用户重新登录 |
| 跨用户读取 PRIVATE 原图 | 非 owner 返回 404，owner 返回 200 | 生产对象存储仍需单对象短时授权策略 |
| 普通用户访问管理员接口 | 未认证 401，USER 403 | 管理员账号和密钥管理依赖部署环境 |
| 公开图片包含证件敏感区域 | 身份证发布要求用户确认号码并完成正面积脱敏框选 | 自动/人工框选仍可能漏遮，真实部署需复核操作规范 |
| 候选重复或并发匹配 | 数据库唯一约束 + upsert；连续匹配保持 candidate ID | 极高并发压测未在本轮执行 |
| 相似度被误当所有权 | 候选只用于缩小范围；必须继续走身份证或 OTHER 核验 | mock embedding 不代表真实语义模型效果 |
| OTHER 回答误判 | 全部关键题匹配且满足置信规则才自动待交接，其余转管理员 | 真实模型阈值仍需脱敏样本校准 |
| 身份证号码枚举 | 确定性校验、HMAC、同账号同候选最多两次并锁定 | 跨账号协同攻击不在两天 MVP 完整解决范围 |
| 同证件多条活动记录 | 成功比对仍检查歧义并转管理员 | 管理员仍需根据审计材料判断 |
| 隐藏信息进入 embedding | embedding 文本只由公开名称、公开描述和公开区域构建；测试覆盖 | 调用真实外部模型前仍需供应商数据处理评估 |
| AI 超时/非法响应 | 适配器结构校验和保守失败路径已有单元/集成测试 | 本轮未执行真实供应商故障演练 |
| 测试数据污染业务库 | E2E 强制 `APP_ENV=e2e` 且数据库名以 `_e2e` 结尾，只清空应用元数据表 | 人工绕过脚本保护仍属于运维风险 |
| 现实世界冒领 | 软件只证明受控核验与留痕，不证明法律所有权 | 需要线下身份核验和学校流程配合 |

任何真实密钥、真实身份证号或真实个人图片都不得进入仓库、截图、演示 seed 或测试日志。
