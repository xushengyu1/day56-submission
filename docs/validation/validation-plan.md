# 测试计划

> 当前为需求级计划。测试用例必须在 `dev.md` 后按 TDD 细化，实际结果只写入 `cases-and-results.md`。

## 测试计划

| 类型 | 用例 | 输入 | 预期 | 优先级 |
|---|---|---|---|---|
| 正常 | 高可信自动进入待交接并由拾得者完成交接 | 候选分≥80、隐藏核验分≥85、综合可信度≥85、至少两题匹配且无风险 | 跳过管理员进入待交接，展示授权联系方式；拾得者可标记已认领；审计链完整 | P0 |
| 正常 | 候选存在但管理员人工驳回 | 相似公开信息 + 冲突隐藏特征 | 申请被驳回并记录人工理由 | P0 |
| 边界 | 题面黑色折叠伞歧义 | 两条同名同色记录，伞柄花纹不同 | 显示相似与缺口，不自动确认 | P0 |
| 边界 | 团队自拟：时间或地点强冲突 | 公开描述向量语义高度相似，但时间/地点明显不符 | 时间/地点维度降低候选分并标记冲突，不因 50 分语义维度直接高可信 | P0 |
| 边界 | 团队自拟：描述信息不足 | 仅“黑色耳机” | 信息不足，不编造特征 | P0 |
| 边界 | 招领隐藏问答不足 | 拾得者只填 0～1 组问答，或两题均未标记关键问题 | 只能保存草稿，不能进入匹配池 | P0 |
| 边界 | 候选高分但隐藏答案部分匹配 | 候选分 90、隐藏核验分 70 | 不自动待交接，进入管理员复核 | P0 |
| 边界 | 整体图片与文本同时存在 | 拾得者上传黑色雨伞整体图 | 图片可展示，但 AI 请求和评分中不包含图片 | P0 |
| 边界 | 四级候选响应字段扫描 | 候选记录同时拥有 PUBLIC、MATCH_ONLY、VERIFICATION、PRIVATE | 普通用户响应只含 PUBLIC；其他级别字段键和值均不存在 | P0 |
| 边界 | 文本向量参与内部召回 | 两条同义描述生成 embedding 并写入 pgvector | 向量相似度参与候选，但原始向量不出现在用户或管理员常规响应 | P0 |
| 失败 | 团队自拟：AI 超时/非法结构 | 测试桩抛出超时或返回非法 JSON | 明确失败/降级，输入不丢失 | P0 |
| 失败 | 普通用户越权获取隐藏答案 | 普通用户请求管理员详情 | 拒绝且响应不含隐藏字段 | P0 |
| 失败 | PRIVATE 提前泄露 | 认领尚未进入待交接时请求拾得者联系方式 | 拒绝或只返回不可逆脱敏值，并记录越权事件 | P0 |
| 回归 | 修复任一边界/泄露问题后重跑主路径 | 固定主路径数据 | 主路径仍完整通过 | P0 |
| 端到端 | 注册、发布、自动/人工路由、交接到审计 | 浏览器操作 + 服务端 + 数据层 | 失主、拾得者、管理员权限正确，每一步有真实状态变化和证据 | P0 |

## 最低覆盖

| 覆盖项 | 最低要求 | 当前计划 |
|---|---|---|
| 正常样例 | 至少 2 个 | 已规划 2 个 |
| 边界样例 | 至少 2 个 | 已规划 6 个 |
| 失败样例 | 至少 2 个 | 已规划 2 个 |
| 回归样例 | 至少 1 个 | 已规划 1 个 |
| 端到端样例 | 至少 1 个 | 已规划 1 个 |
| 题面外边界/失败 | 至少 3 个 | 时间/地点冲突、信息不足、AI 异常、越权共 4 个 |
