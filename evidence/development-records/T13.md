## 4. Green（实际实现）

### 认证系统
- JWT access token 仅存储在内存变量中，不写入 localStorage/sessionStorage
- 401 响应自动尝试 refresh，失败则清除状态跳转登录页
- Mock 模式下模拟 500ms 延迟，模拟真实网络体验

### 路由守卫
- `RequireAuth`：未登录跳转 `/login`，保存来源路径
- `RequireAdmin`：非 ADMIN 角色显示 403 无权页面
- 加载中显示 spinner 状态

### 布局
- `UserLayout`：顶部 Navbar + 内容区
- `AdminLayout`：顶部导航 + 左侧菜单（复核队列/审计日志）+ 内容区
- 管理员布局独立于普通用户，紫色主题

### 首页
- 双入口卡片："我丢失了物品" / "我捡到了物品"
- 最近记录列表（Mock 数据）
- 底部统计卡片

## 6. 关键设计决策

| 决策 | 理由 |
|---|---|
| JWT 存内存不存 localStorage | PRD 安全要求：不在浏览器持久化敏感值 |
| Mock API 内置 | 后端尚未实现，前端可独立运行演示 |
| Ant Design + Tailwind 混用 | Ant Design 提供复杂组件，Tailwind 处理自定义布局 |
| 路由守卫在路由层 | 集中管理权限，不在每个页面单独检查 |
