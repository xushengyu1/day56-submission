# T18：安全、失败与全量回归

**执行日期：** 2026-07-17

**状态：** 已完成

## 安全与失败覆盖

- 身份证完整号码只允许进入 identity-confirmation 请求体。
- token 不进入 URL、localStorage 或 sessionStorage。
- 未认证管理员接口返回 401；USER 返回 403。
- 跨用户 PRIVATE 原图返回 404；owner 读取返回 200。
- 同账号两次身份证错误后锁定并显示人工复核入口。
- OTHER 错误答案进入管理员复核。
- 未匹配复核可推荐候选，但不能直接进入待交接。
- 重复匹配由唯一约束与 upsert 保证候选幂等。

## 本轮缺陷闭环

真实 E2E 发现同一失物的两个相邻匹配请求会各插入候选，数据库记录创建时间只差约 16ms。修复采用用户确认的 O-A：`(lost_record_id, found_record_id)` 唯一约束、迁移去重并重定向引用、候选 upsert。修复后连续调用保持 candidate ID，OTHER E2E 完整通过。
